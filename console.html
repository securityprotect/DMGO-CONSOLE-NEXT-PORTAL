Where to build from here

The backend already exposes every console API under /api/admin/* (users, plans, billing, tickets, automations, instagram, whatsapp, diagnostics, settings…). Each sidebar item above is a placeholder — drop a page next to console.html, call DMGO_API.get('/api/admin/<resource>') and render. Auth + the API client are already wired (cookie-based, same-origin). See CONSOLE-SETUP.md.
